# Build Persian RTL checkout flow

## Goal
Build a small but portfolio-ready Persian RTL checkout flow UI.

## UI Requirements
- Multi-step checkout:
  - اطلاعات ارسال
  - روش پرداخت
  - بررسی سفارش
  - تکمیل خرید
- Persian form labels and placeholders
- Order summary card
- Payment method selection
- Validation messages in Persian
- Success state
- Responsive mobile-first layout
- Accessible form controls

## Acceptance Criteria
- All visible UI text is Persian in RTL direction
- Stepper and four checkout stages are implemented
- Validation messages are shown in Persian
- Order summary and success state are visible
- Build passes successfully
