# persian-checkout-flow

A portfolio-ready Persian RTL checkout flow built with React, TypeScript, Vite, and MUI.

## Tech Stack
- Vite
- React
- TypeScript
- MUI

## Features
- Multi-step checkout flow
- Persian RTL form labels and placeholders
- Shipping information form
- Payment method selection
- Order review and summary card
- Persian validation messages
- Success state after completion
- Responsive mobile-first layout and accessible controls

## Run Locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Note
All visible UI content is Persian and rendered in RTL layout.
