# Add Persian RTL checkout flow

## Summary
Implement a Persian RTL checkout flow using Vite, React, TypeScript, and MUI.

## Included Changes
- Initialized project and installed MUI dependencies
- Built stepper-based checkout structure
- Added shipping form step
- Added payment method step
- Added review step with order summary
- Added Persian validations and success state
- Improved accessibility for form controls
- Added project documentation files

## Checks
- npm install
- npm run build

## Acceptance Criteria
- UI is Persian and RTL
- Multi-step flow is complete and responsive
- Validation and success states work
- Build completes without errors
